# archive/

歷史文件，不代表成品規格。

`捕手偷好球專案企劃書.md` 是動工前寫的研究計畫，內容是「預計要做什麼」。
成品在若干地方與它不同，以 repo 根目錄的 README 為準：

| 項目 | 企劃書（計畫） | 成品（實際） |
|---|---|---|
| 球季範圍 | 2021–2025 | 2021–2023 |
| 樣本 | 約 175 萬球 | 106 萬顆判定球（建模 104 萬） |
| 階層模型引擎 | R `glmmTMB` 或 PyMC | Python statsmodels 變分貝葉斯 |
| XGBoost 黑箱對照 | 列為主力對照 | 未做 |
| 主審資料來源 | 未指定 | MLB Stats API（以 `game_pk` join） |

企劃書第 8 節把 2026 年 ABS 制度形容為「一項技術的死亡」。ABS 挑戰制度自 2026 年
球季起在大聯盟例行賽實施，但它是「挑戰制」而非全自動判定，較準確的說法是
framing 的衡量方式與價值可能因此改變，而非消失。
